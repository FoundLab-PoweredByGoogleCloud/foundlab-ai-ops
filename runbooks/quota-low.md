# Runbook — Low Agentic Quota

## AMBER
- stop speculative parallelism;
- prefer routine model classes for exploration;
- reserve premium reasoning for material work.

## RED
- reduce subagents to one;
- move mechanical work to deterministic scripts;
- reserve high-cost execution for high-risk or blocking work.

## CRITICAL
- block non-critical agentic execution;
- preserve incident reserve;
- use independent API billing/fallback only when it is explicitly configured and cost-approved;
- do not claim live provider telemetry unless a supported source is actually integrated.

The local quota snapshot is an operator input, not provider telemetry.
